Neon Bay is a complete open-world crime game in the spirit of GTA 6: explore a procedural dusk city on foot or by car, steal cars, outrun the Bay PD's wanted system, and work through a four-mission story with combat, a HUD minimap and procedural sound — all running offline in the browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
